# Соответствие кейсу 2

Источник требований — описание кейса Voice Router и исходный [README набора](../data/README.ru.md). Предметные данные организаторов сохранены без изменений; дата расчётов — **2026-10-01**.

| Требование | Где реализовано | Проверка / граница |
|---|---|---|
| Веб-симулятор клиента и супервизора | `public/index.html`, `public/app.js` | Общая рабочая область: разговор слева, маршрут/действия/контекст справа |
| Микрофон и голосовой ответ | AudioWorklet, `lib/providers.mjs` | Оба Live API проверены синтетическим PCM; физический микрофон проверяется вручную |
| Текст только как резерв | «Без микрофона», текстовый composer | Live-модель возвращает голос и для текста |
| Выбор сценария через LLM | `buildInstructions`, `route_turn` | Нет encoder classifier и dev-таблицы в runtime |
| 40 бизнес-сценариев + 3 SYS | `data/scenarios.json`, `lib/catalog.mjs` | Все ID присутствуют в инструменте и серверной диспетчеризации |
| RU / KK / смешанный язык | Prompt, локализованные ответы и UI | Полный dev-прогон с разбиением по языкам опубликован |
| Несколько намерений, слот-продолжение, смена темы | `lib/engine.mjs` | Очередь, отдельные карты слотов, прерванные темы; локальные регрессии |
| Факты только из KB/моков | `engine.mjs`, `knowledge.mjs` | SC40 даёт пути к выбранным фактам; неизвестная тема → `not_found` |
| Отдельное подтверждение необратимых операций | Preview → confirmation → execute | Новые аргументы требуют нового preview; повтор хода идемпотентен |
| Неопределённость и оператор | SYS_UNCLEAR, альтернативы, общий handoff context | Низкая уверенность/недоступное действие не обозначаются успешной операцией |
| Транскрипт и объяснение после реплики | Trace event, панель маршрута | Краткое объяснение на основе запроса, без скрытой цепочки рассуждений |
| Фактические задержки | Server monotonic clock, playback notification | Недоступные STT/TTS и VAD-тайминги остаются `null`, не имитируются |
| Запуск одной командой | `docker compose --env-file .env.jury up --build -d --wait` | После клонирования и запуска Docker; ключи для жюри включены, приложение + PostgreSQL |
| README: стек, архитектура, запуск, основной сценарий, проверка | [README](../README.md) | Сохранённые предсказания пересчитываются оригинальным оценщиком без API |
| Бонус за скорость | Панель замеров | Не заявлен: нет медианного акустического прогона по согласованному набору |

## Дополнительно к обязательному минимуму

Постоянный журнал PostgreSQL, просмотр истории в том же браузере, прерывания с отбрасыванием старого аудио, два провайдера, выбор моделей с проверенными подсказками, предварительный просмотр действий и ссылки на факты KB.

## Что не заявляется

Production CRM/платежи/телефония, полноценный семантический RAG, перенос сессии между браузерами, восстановление оборванного Live-соединения, калиброванная вероятность уверенности модели, проверка скрытого набора и гарантированная задержка. Функциональная точность маршрута на dev-наборе отдельно от полноты исполнения всех предметных операций и качества голоса.

# UI assets

- `hackalem-logo.svg` and `halyk-logo.png` are the assets supplied for this HackAlem demonstration. They are reproduced unchanged. The HackAlem SVG contains an embedded PNG and internal fragment references; no scripts, event handlers or external references were found.
- `NotoSans-400.ttf`, `NotoSans-600.ttf`, and `NotoSans-700.ttf` were obtained from the official [Google Fonts Noto Sans service](https://fonts.google.com/noto/specimen/Noto+Sans) on 2026-09-23. Their source family is maintained in [google/fonts/ofl/notosans](https://github.com/google/fonts/tree/main/ofl/notosans).
- Font licensing is included in [NotoSans-OFL.txt](NotoSans-OFL.txt): SIL Open Font License 1.1, Copyright 2022 The Noto Project Authors. The font files are served locally and require no Google Fonts request from the browser.
- The delivered font cmap tables were checked for Latin, the full Russian and Kazakh alphabets, numerals, and the tenge sign. All required glyphs were present in all three weights. Font display uses `swap` so loading does not hide interface text.
